# Регламент работы (ред. 2 — от 17.10.2026)

## 1. Формат — ПРОСТОЙ
- Работаем по **MD-файлам** (списки дел) + **Календарь** (/Календарь/Календарь.html, стилистика Google Календарь: дата сверху → список дел).
- Главный документ планов: **/Календарь/Календарь_дел.md**.
- Нодовая среда (конструктор) — УБРАНА, возвращемся к ней ПОЗЖЕ, когда будет время. Не усложнять.

## 2. Работа над документом
1. Если документ не подтверждён — дорабатываем его.
2. Агент ОБЯЗАН спросить: **«Подтверждаете готовность?»**
3. Ответ матери: «да, подтверждаю» → статус **«готов»**, сохранение, отметка в списке.
4. Без подтверждения документ остаётся «в работе» / «на подтверждении».

## 3. Статусы документов
черновик · в работе · **на подтверждении** (ждёт вопроса и «да») · **готов** · справочно

## 4. События
- Каждое событие → подробно в /История/История.txt + при необходимости файл в /История/События/.
- По событию — дела в календаре (дата → список).

## 5. Календарь
- Дела по датам: /Календарь/Календарь_дел.md (текст) и /Календарь/Календарь.html (визуал).
- Отмечать выполненное; статусы документов — в списке.
